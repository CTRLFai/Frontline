# Frontline

A Lux-style conquest game for the phone, built as a web app (PWA).

Play: https://ctrlfai.github.io/frontline/

On iPhone, open the link in Safari, tap Share, then Add to Home Screen. It then opens full screen with no browser bars.

The built-in maps are Domination community maps (domination.sourceforge.io). Any other Domination map zip can be added in-game with Select Map > Import Map.
